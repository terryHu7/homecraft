# Homecraft v0.2.0

This release introduces the Photo Studio, adds an in-world selfie camera pose, and ships fixes for viewfinder controls, exported captures, and player movement after web zip navigation.

## What's new

- **Photo Studio**: Press `P` (or `C`), click the camera button in the corner, or tap the Camera app on the phone to open the in-world studio.
- **Aspect ratios**: Switch between `16:9` landscape, `9:16` portrait, and `1:1` square viewfinders with clean geometric icons and left-aligned typography.
- **Selfie camera**: Frame your character raising a phone and facing the camera from the chest up, with background scenery and portals aligned behind.
- **Live scene tuning**: Adjust camera angles, lighting phases (day, dusk, night), and weather conditions (clear, rain, snow) directly inside the viewfinder.
- **Mac window frame & watermark**: Toggle an Apple-style window header with a live domain pill, then export high-resolution PNG captures with a subtle micro-watermark. The window bar and watermark scale with the viewfinder, so the exported image matches the preview.
- **Flexible viewfinder**: Drag, resize, wheel-zoom, and pinch-zoom the crop frame. The frame stays inside the visible area on both desktop and phone, so it cannot be scaled or dragged off screen.

## Fixes

- Bounded viewfinder zoom, drag, eight-direction resize, pinch zoom, and window resizing to the current viewport.
- Replaced the emoji camera-flip control with a two-arc SVG icon, matching the native phone camera switcher.
- Anchored the Homecraft badge to the viewfinder's lower-right corner, softened the corner bracket behind it, and kept the exported PNG in the same position.
- Refined the selfie arm pose so only a small foreground section of the hand is visible, with the head turned toward the raised phone.
- Fixed character floating and drift by clearing the departure support state upon `zipTo` arrival.
- Isolated scene popover selectors to prevent test collisions, and refined watermark clearance from the crop frame corner bracket.

## Updating

Requires Node.js 22 or newer. Run these commands in the **source project folder**, where `package.json`, `home.config.js`, and `engine/` live, not in `dist/`.

New forks:

```sh
npm run update -- --check
npm run update
```

Older forks do not need to merge upstream or add a script. Use the standalone tool:

```sh
npx --yes https://github.com/terryHu7/homecraft/releases/latest/download/homecraft-updater.tgz --check
npx --yes https://github.com/terryHu7/homecraft/releases/latest/download/homecraft-updater.tgz
```

`--check` is read-only. The updater changes `engine/` and adds an update guide pointer to `AGENTS.md`; it preserves `world/`, `index.html`, root `assets/`, `home.config.js`, `homecraft.json`, package scripts, and deployment files. It backs up the current engine before applying changes, supports rollback, and stops without writing anything when your customizations conflict with an upstream change. A source update is not a live update: preview and test locally, then commit and redeploy through your existing hosting.

This release contains `homecraft-engine.json`, `homecraft-updater.tgz`, and `SHA256SUMS`. Read [Update Homecraft](https://github.com/terryHu7/homecraft/blob/v0.2.0/engine/UPDATING.md) for conflict reports, rollback, pinned versions, and offline bundles.
