# Homecraft v0.2.0

This release introduces the Photo Studio, adds a Watch Dogs-style selfie camera, and fixes player positioning after web zip navigation.

## What's new

- **Photo Studio**: Press `P` (or `C`), click the camera button in the corner, or tap the Camera app on the phone to open the in-world studio.
- **Aspect ratios**: Switch between `16:9` landscape, `9:16` portrait, and `1:1` square viewfinders with clean geometric icons and left-aligned typography.
- **Watch Dogs selfie camera**: Frame your character facing the camera from the chest up, with background scenery and portals aligned behind.
- **Live scene tuning**: Adjust camera angles, lighting phases (day, dusk, night), and weather conditions (clear, rain, snow) directly inside the viewfinder.
- **Mac window frame & watermark**: Toggle an Apple-style window header with live domain pill, and export clean high-resolution WebP/PNG captures with a subtle micro-watermark.
- **Bug fixes**: Fixed character floating/drift by clearing departure support state upon `zipTo` arrival; isolated scene popover selectors to prevent test collisions.

## Updating

- In your Homecraft workspace, run:
  ```sh
  npm run update -- --check
  npm run update
  ```
- Or run the standalone updater:
  ```sh
  npx --yes https://github.com/terryHu7/homecraft/releases/latest/download/homecraft-updater.tgz
  ```

After updating, preview and test your website locally, then commit and redeploy through your existing hosting setup.
