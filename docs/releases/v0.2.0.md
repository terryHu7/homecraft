# Homecraft v0.2.0

![Photo Studio in Terry's Home — default view](https://github.com/terryHu7/homecraft/releases/download/v0.2.0/photo-studio-default.webp)

![Photo Studio in Terry's Home — selfie view](https://github.com/terryHu7/homecraft/releases/download/v0.2.0/photo-studio-selfie.webp)

Photo Studio lets you frame your home, tune the scene, and export a PNG.

## What's new

- **Photo Studio** — open with `P` / `C`, the corner camera button, or the phone Camera app.
- **Aspect ratios** — `16:9`, `9:16`, `1:1`, with live camera angle, lighting (day / dusk / night) and weather controls.
- **Selfie camera** — a chest-up pose with your home and portals in the background.
- **PNG export** — optional desktop-style window bar and a subtle homecraft watermark, matching the preview; up to 1920 px on the long edge.
- **Adjustable viewfinder** — drag, resize, wheel-zoom or pinch to frame exactly what you want.

## Fixes

- Bounded all viewfinder gestures — zoom, drag, resize, pinch and window resize — to the viewport on desktop and phone.
- Replaced the emoji camera flip with a two-arc SVG; the homecraft badge now stays in the lower-right corner in both preview and export.
- Refined the selfie arm pose; fixed character floating and drifting after a portal jump.

## Updating

Requires Node.js 22 or newer. Run from the source folder (where `engine/` and `package.json` live), not `dist/`.

New forks:

```sh
npm run update -- --check
npm run update
```

Older forks — one command, no upstream merge needed:

```sh
npx --yes https://github.com/terryHu7/homecraft/releases/latest/download/homecraft-updater.tgz
```

- Add `--check` to preview changes without writing anything.
- Only `engine/` is updated. Your `world/`, pages, config, assets and deployment files stay untouched.
- It backs up before applying changes, supports rollback, and stops with a conflict report if your edits overlap.
- A source update is not a live update: preview locally, then commit and redeploy.

Full guide: [Update Homecraft](https://github.com/terryHu7/homecraft/blob/v0.2.0/engine/UPDATING.md).
