This release introduces the Homecraft plugin system, adds a 3D animated startup loading logo, and includes mobile UI fixes.

## What's new

- **Plugin host (`engine/plugins.js`, `PLUGIN_API = 1`)** — loads opted-in site plugins from `world/plugins/<id>/` configured through `plugins` in `home.config.js` (empty by default).
  - Supports `build(ctx, options)` and `setup(host, options)` hooks for world geometry, collision obstacles, interactive hotspots, baked lighting, HUD corner buttons, overlays, keyboard input, minimap markers, and per-frame updates.
  - Isolates plugin failures and cleans up registered resources automatically without breaking the rest of the site.
  - Exposes `__home.plugins.status()` and `__home.plugins.get(id)` in the console for debugging. See [docs/plugins.md](https://github.com/terryHu7/homecraft/blob/v0.3.0/docs/plugins.md) for the plugin host API and [Homecraft Plugins](https://github.com/terryHu7/homecraft-plugins) for the plugin repository and CLI.
- **3D animated startup logo (`engine/ui/loading-logo.js`)** — renders a 3D grass block with a one-shot camera reveal and slow orbit alongside a live loading percentage indicator in Chinese and English, respecting `prefers-reduced-motion` and disposing WebGL resources when loading completes.
  - Existing forks continue working without editing `index.html`. To enable the 3D startup logo on an older fork, copy the updated `#loading` markup and `<script type="module" src="engine/ui/loading-logo.js"></script>` from the template `index.html`.

## Fixes

- Removed the leftover `backdrop-filter` blur behind the transparent Photo Studio toolbar on mobile (`engine/style.css`).
- Allowed mobile HUD corner buttons to wrap cleanly when plugins add extra controls (`engine/style.css`).

## Updating

Requires Node.js 22 or newer. Run from the source folder (where `engine/` and `package.json` live), not `dist/`.

New forks:

```sh
npm run update -- --check
npm run update
```

Older forks — one command, no upstream merge needed:

```sh
npx --yes https://github.com/terryHu7/homecraft/releases/latest/download/homecraft-updater.tgz
```

- Add `--check` to preview changes without writing anything.
- Only `engine/` is updated. Your `world/`, pages, config, assets and deployment files stay untouched.
- Existing forks from `v0.1.0` onward gain plugin host support after updating `engine/`, without modifying `index.html`, `world/build.js`, or `tools/build.sh`.
- It backs up before applying changes, supports rollback, and stops with a conflict report if your edits overlap.
- A source update is not a live update: preview locally, then commit and redeploy.

Full guide: [Update Homecraft](https://github.com/terryHu7/homecraft/blob/v0.3.0/engine/UPDATING.md). This release contains `homecraft-engine.json`, `homecraft-updater.tgz` and `SHA256SUMS`.
