# Homecraft v0.1.1

This release adds shared engine updates for existing forks. It includes the Portal directory loading and physical keyboard fixes, with compatibility for mailbox forms that have no subject field.

- New forks: run `npm run update -- --check`, then `npm run update` in your source project folder.
- Existing forks: use the standalone command below. No upstream merge or npm registry package is required.
- Local engine changes are preserved when upstream has not changed that file. Conflicting changes stop the whole update and produce base/local/incoming files for your Agent.
- The first update appends an upgrade guide pointer to `AGENTS.md` without replacing existing rules. Future Agents can check official Releases when you request an upgrade or diagnose a related engine issue.
- The updater backs up the engine, supports rollback, and preserves site layouts, content, configuration, assets, and deployment files. Existing forms without a subject field derive the subject from the note; forms with the field still require it.

```sh
npx --yes https://github.com/terryHu7/homecraft/releases/latest/download/homecraft-updater.tgz --check
npx --yes https://github.com/terryHu7/homecraft/releases/latest/download/homecraft-updater.tgz
```

Use Node.js 22 or newer. After updating, preview and test your website, then commit and redeploy through your existing hosting. Directory listing does not update deployed code. Optional mailbox Workers and regular-website Portal plugins require separate deployment.

Read [Update Homecraft](https://github.com/terryHu7/homecraft/blob/v0.1.1/engine/UPDATING.md) for conflicts, rollback, pinned versions and offline bundles. This release contains `homecraft-engine.json`, `homecraft-updater.tgz` and `SHA256SUMS`.
